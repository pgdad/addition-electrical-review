# How to use this package

1. Unzip, then open a terminal in the `addition-electrical-review` folder.
2. Start Claude Code there (`claude`). Pick your model with `/model`.
3. Claude Code reads CLAUDE.md automatically. Paste this prompt:

   Read CLAUDE.md, then the notes and every drawing and plan. Do Task 1 (write REVIEW.md), then
   Task 2 (build lights-3d.html and lights.json). Show me the top 10 review findings when done,
   and tell me how to open the 3D model.

4. Open lights-3d.html in a browser when it's done.

Optional tools that help: poppler-utils (pdftotext, pdftoppm) for reading the plan PDFs.
